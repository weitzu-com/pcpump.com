# PCP 页面与询价预览

本次范围：英语PCP系统完整页面与技术询价预览。沿用DJI产品导航和技术规格结构；未部署生产。

- 系统预览：http://127.0.0.1:3101/en/pcp-systems
- 规格入口：http://127.0.0.1:3101/en/progressive-cavity-pumps
- 询价预览：http://127.0.0.1:3101/en/request-quote

页面包含59个井下泵型号、8种材料、23个驱动配置；搜索、产品家族过滤、最多三项对比、型号带入询价、应用带入询价、参数CSV下载。GBF、VED和PMM图片已目视核对，修正了图片与名称对应关系。GLB521的源表标识/排量差异保留；PMM轴向载荷不使用一条泛化数值冒充逐型号额定值。

询价包括联系人、项目与系统需求、可选工况字段、最大2MB PDF附件、复核、同意、本地保存、回执和摘要下载。ESPCP与地面驱动提供不同字段路径。未知参数可留空。服务器重复请求返回同一编号，修改内容后重用同一编号返回冲突；字段、来源域及附件均在服务端检查。没有公开读取私人记录的接口。

## 运行与生产边界

当前预览运行目录：`/tmp/pcpump-runtime`，监听`127.0.0.1:3101`。该运行副本是临时快照，后续源码变化需同步或在原项目依赖恢复后直接启动。
