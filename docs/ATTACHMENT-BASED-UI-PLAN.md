## 二、从第一性原理推导方案

客户要完成的是确认井况 → 理解系统 → 缩小设备范围 → 检查材料和接口 → 提交技术需求。附件的复杂度来自系统配套关系和技术约束，单纯增加产品照片无法解决选型问题。

推荐“系统方案 + 参数产品库 + 技术询价”的组合。导航建议：Products、Solutions、Engineering & Quality、Resources、Request Engineering Review。

- Products：按上表产品家族进入，PCP、ESPCP和ESP电机分别命名，避免混淆。
- Solutions：按已被附件支持的问题进入，展示关联产品、所需工况、限制和资料来源。
- Engineering & Quality：将生产线、橡胶测试、压力测试、材料与表面处理证据独立呈现。
- Resources：按产品家族提供参数表、选型数据表、说明书和可核查文件。

上轮已检查截图：左侧主张及两个行动入口，右侧分行展示行业入口。保留这种任务分流结构；PCPUMP右侧改为PCP、ESPCP、往复式举升、驱动与改造等系统入口，另提供工况导航。不能把这张客户/行业页截图误称为Retool官网首页。

## 六、上线前应解决的数据歧义

1. 附件PDF8—9流量以参考转速归一化，不能直接称为任意工况的日产量；水柱扬程也不能直接当作井深。
2. PDF10橡胶表的星级和表头需要逐格人工复核，保留工作温度/最大温度两列，不将星级转换为浓度限值。
3. PDF16系统表列120℃，PDF17电机表出现“H级180”等内容，含义须澄清，不能合并成系统180℃额定温度。
4. 部分表头存在单位/拼写混杂，原值、来源与审核后字段须分别保存。
5. 认证、产量、累计应用及节能等均属附件陈述；发布日期、证书持有人/范围/有效期及测试条件待补。
6. 附件没有为钻机、作业车辆、管材等现有网站其他范围提供本次证据；据此改版时不擅自扩充或删除其业务。

## 七、实施顺序与验收

先做PCP系统概览、井下泵型号表、橡胶适配表、地面驱动配套页和技术询价，再扩展其他系统。原始PDF页码保留为每条技术数据的来源；同一家族内比较，避免将不同物理含义的参数横向混排。

验收：客户能从工况找到系统，也能从型号找到参数；参数显示单位、参考条件、来源和待补项；未知工况可发起咨询；询价摘要准确带上所选型号和用户条件；提交状态与真实收件分别验证。本报告不代表工程选型、报价或网站改版已经完成。


## 八、2026-10-17 UI方案收敛与交付基线 V3

目标：人工举升系统方案站＋技术产品库＋工程询价，优先走通PCP系统→井下泵→橡胶→地面驱动→工程询价；其他产品完整保留，避免同等曝光稀释PCP。

受众：采购/EPC、工程与运维；新访客先理解系统，回访者直接查型号和文件。

语言：延续现有EN/ES/RU架构；英文优先验证路径，其他语言需技术审核；中文扩展待确认。

技术栈：现有Next.js 16.3.2、React 19.2.8、TypeScript；域名www.pcpump.com。此次交付范围为方案及需求单，未变更网站或部署。后续部署地区、数据服务、预算及接收队列须冻结，发布后需分别验证页面、询盘接收及客户视觉确认。

UI选择：Retool任务分流＋DJI规格层级＋Linear工程询价，统一浅色工业视觉与品牌橙色。PCP在首屏有独立主张与主CTA，右侧PCP入口优先，ESPCP/往复举升/驱动改造次级；按工况入口置于下一层。

动效：首屏与Overview解释转子定子和两类动力路径；规格、来源和询价区保持稳定阅读。参考页面截图并不能证明这些动效已存在，均为本项目新增设计。

可复用资产：原点检索流程、网站全生命周期手册索引、PDF/PPTX制作与渲染验证脚本、现有三语代码及产品数据；cnps.ae、leisa.com、laotzu.ai属于候选复用站点，本轮未审计源码，不据此宣称直接可移植。

参考验证边界：本轮Refero页面与截图不能访问，本地浏览器控制未启用；UI观察依据用户输入及已有研究，不声称新完成截图审阅。SLB与NOV官方内容页面本轮可读；仅参考内容组织，不使用其产品性能或品牌背书。

交付：71页V3 PPTX、PDF预览、160项需求追踪表，含3页原生可编辑布局示意。布局示意不是正式视觉定稿，也不代表官网功能完成。
