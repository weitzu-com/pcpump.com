# PCP 预览检查与修复

范围：本地3101预览，型号对比、参数下载、技术询价；无生产部署或销售消息发送。

## 已修复

- 对比模式独立于搜索/产品家族筛选，避免跨家族选择被隐藏；空选择时仍可返回型号列表，增加状态和空列表说明。
- 询价编辑后显示已选附件并支持移除，文件选择器清空后仍保留附件状态，允许重新选择同一个文件。
- 返回编辑后重置同意状态；地面驱动的待补数据按扭矩/载荷/转速显示。
- 摘要下载延迟释放Blob地址，避免下载尚未读取时地址失效。
- 预览提交先完整写入临时文件，再原子建立最终记录，避免并发重试读到半写文件。最终记录权限600，临时文件自动清理。
- 回执长编号允许换行，步骤与操作按钮允许折行；这些为代码层预防修复，尚未由真实视口截图验证。
