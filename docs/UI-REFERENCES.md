# PCPUMP UI 参考筛选

核查日期：2026-10-17。来源：既有 Refero 截图研究与用户提供的页面观察；本轮远程访问失败，不宣称再次完成截图或交互核验。仅研究，未修改网站。

## 第一性原理

油田设备采购需要依次降低三个不确定性：工况适配、设备选择、供应商能否给出有效方案。UI 应让访客完成“找到工况入口 → 查看产品和技术依据 → 提交选型数据”。视觉判断是设计建议，尚无转化率实验支持。

## 1. Retool：行业入口页，作为首页结构参考

- Refero：https://refero.design/pages/93a7796a-78cc-4422-a944-3339da394857
- 原始截图：https://images.refero.design/screenshots/retool.com/desktop/2012c1ec-dddb-4b06-a194-b3f42fd31650/0.jpg
- 实际观察：左侧价值主张、说明与两个行动入口；右侧白色面板列出行业，分隔线与箭头强化入口层级；下方继续内容。
- PCPUMP 映射：左侧说明 PCP 和人工举升能力；右侧改为重油、高含砂、黏性流体及其他经确认的应用入口。主按钮 Request engineering review，次按钮 Explore systems。
- 理由：客户知道自己的问题时，可直接进入相关方案；首屏同时给出产品定位与下一步。
- 不照搬：紫色渐变、免费试用文案、行业名称及客户背书。该截图为行业/客户入口页，不应误称其官网首页。

## 2. DJI Mavic 3 Pro：产品详情主参考（替换 Elektron）

- Refero：https://refero.design/pages/b665a7e7-8537-4401-9d1f-9db1e8ab97e2
- 依据：用户提供的观察与本地 ATTACHMENT-BASED-UI-PLAN.md 中的既有截图研究；本轮 Refero 与截图地址无法读取，未新增交互验证。
- 借鉴：产品局部导航、分组技术规格、名称/数值交替行、下载与说明入口。
- PCPUMP映射：Overview、Specifications、Elastomers、Driveheads、Downloads、Engineering Review；按液力、几何、材料、接口、适用条件组织。
- 新增设计：型号过滤、同族比较、来源页码、工程询价上下文、手机分组展示；不能声称参考截图已具备。
- 不照搬：消费购买流程、无人机参数及性能承诺。Elektron不再作为产品详情主参考。

## 3. Linear：销售联系页

- Refero：https://refero.design/pages/245f83bd-5b8e-4c9f-a2d4-7012ab17a350
- 原始截图：https://images.refero.design/screenshots/linear.app/desktop/b1734499-1f6a-4a26-98cf-04c6f5a30d7f/0.jpg
- 实际观察：左侧说明联系销售能获得什么，并提供独立支持入口；右侧单列表单包含姓名、工作邮箱、企业规模及需求描述，底部有邮件替代路径。
- PCPUMP 映射：左侧明确技术团队将协助配置选择、识别缺失数据、确认所需文件；右侧先收联系人、公司、项目国家和需求，再以可选展开区收流量、黏度、含砂、温度、井深和电力条件，字段附单位及“不确定”选项。附件、分组与展开均为新增设计建议，并非该截图已有功能。
- 理由：说明提交价值，同时让已掌握参数的工程师提供有效输入，初次采购也能开始沟通。
- 不照搬：Company size 作为主要资格字段、全黑配色、软件演示文案、未经确认的回复时效。

## 组合建议与验收

以 Retool 的首屏双栏为骨架，DJI 的分组规格与产品局部导航为详情层，Linear 的价值说明加表单为询价层。统一采用 PCPUMP 自有摄影、浅色底、深色正文和现有橙色行动强调。

实施后检查：1280×720 首屏可见定位、工况入口和主按钮；从首页进入相关产品无需猜测分类；技术参数附单位与来源；未知参数不阻止初步询价；提交后的成功状态与实际接收结果分别核实。Refero 为静态截图证据，未据此宣称参考站点交互或转化效果已验证。
